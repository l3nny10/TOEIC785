# TOEIC 785

Application de révision du TOEIC (45 leçons de grammaire, 805 mots de vocabulaire), utilisable hors ligne sur iPhone.

## Mettre l'appli en ligne avec GitHub Pages

1. Sur github.com, clique sur **New repository**. Nom : `toeic785`. Choisis **Public**, puis **Create repository**.
2. Clique sur **uploading an existing file**. Glisse **tout le contenu** de ce dossier (le fichier `index.html` doit être à la racine, avec les dossiers `data` et `icons`). Clique sur **Commit changes**.
3. Va dans **Settings → Pages**. Dans « Branch », choisis **main** et **/ (root)**, puis **Save**.
4. Attends 1 à 2 minutes. L'adresse de l'appli s'affiche en haut de la page : `https://TON-PSEUDO.github.io/toeic785/`.

## L'installer sur l'iPhone

1. Ouvre l'adresse dans **Safari** (pas Chrome).
2. Touche le bouton **Partager** (carré avec une flèche), puis **Sur l'écran d'accueil**, puis **Ajouter**.
3. Ouvre l'appli une première fois avec internet : elle se met en mémoire. Ensuite, elle fonctionne sans connexion.

## Bon à savoir

- Ta progression est enregistrée dans l'appli, sur le téléphone. **Ne supprime pas l'icône** de l'écran d'accueil : ça effacerait ta progression.
- De temps en temps, fais **Progrès → Exporter ma progression** : une copie va dans l'app Fichiers. En cas de problème, **Restaurer une sauvegarde** la remet.
